# AI Automation Sprint

A 30-day practical journey to learn AI automation, build real workflows, document progress, and develop client-ready skills.

## Goal

- Learn practical Python for automation
- Learn n8n workflow automation
- Integrate AI APIs
- Build real automation workflows
- Create portfolio projects
- Develop client-ready automation skills

## Learning Philosophy

**20% Learn · 80% Build**

Avoid tutorial hell. Learn only what is necessary for the current task.

## Learning Loop

**Understand → Observe → Predict → Learn → Code → Run → Debug → Review → Rebuild → Apply**
